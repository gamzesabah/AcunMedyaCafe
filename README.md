#  AcunMedyaCafe

A modern cafe management and content management web application built with ASP.NET Core MVC and Entity Framework Core.

This project was developed as part of the AcunMedya Academy C# Programming Training and focuses on modular architecture, admin panel management and responsive web design principles.

---

#  Project Overview

AcunMedyaCafe is a dynamic cafe website that allows businesses to showcase products, manage content and improve customer interaction through a dedicated admin panel.

The application includes:

* Dynamic cafe website
* Admin management panel
* Product & category management
* Blog system
* Gallery management
* Customer comments section
* Responsive user interface

---

#  Features

##  Admin Panel

* Manage products and categories
* Update homepage content
* Manage gallery and social media sections
* CRUD operations for all dynamic content
* Easy-to-use management dashboard

##  Cafe Website

* Home page
* About section
* Product menu
* Blog section
* Gallery page
* Customer comments
* Responsive modern UI

#  Architecture

The project follows the ASP.NET Core MVC architecture pattern:

```bash id="s9x4ja"
Controller → Service Logic → Entity Framework Core → SQL Server
```

The application uses:

* Area structure for modularity
* Dependency Injection for maintainability
* Entity Framework Core for database management
